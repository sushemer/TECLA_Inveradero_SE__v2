# Documentación del proyecto

Esta carpeta contiene la documentación técnica de la parte embebida y sus enlaces de integración.

- `arquitectura/`: arquitectura, decisiones, diagnóstico y árbol de trabajo.
- `protocolo/`: protocolo ESP-NOW y formato de comunicación.
- `referencias/`: documentación oficial, repositorios de apoyo y videos separados por sensor, comunicación, energía, seguridad, API y pruebas.
- `pruebas/`: compilación, metodología y próximos pasos de validación.
- `talleres/`: Talleres realizados en la materia de Proyecto de Carrera (2026-2).

El firmware permanece en `firmware/` y no se reorganiza desde esta documentación.
